## 🎯 หลักการทำงานของ AI

### 1. Intent Recognition (การเข้าใจเจตนา)

AI จะวิเคราะห์ว่าผู้ใช้ **"ต้องการทำอะไร"**

| ข้อความผู้ใช้ | เจตนาที่ AI เข้าใจ |
|-------------|-------------------|
| "จองรถหน่อย" | 🚗 ต้องการจองรถ |
| "ดูรายการจองของฉัน" | 📋 ต้องการดูประวัติ |
| "ยกเลิกการจอง" | ❌ ต้องการยกเลิก |
| "สวัสดี" | 👋 ทักทาย |
| "รถว่างไหม" | 🔍 ตรวจสอบรถว่าง |

**แนวคิด:** เหมือนการสอนให้ AI จำ "รูปแบบประโยค" ที่หลากหลาย แล้วจัดกลุ่มว่าประโยคแบบไหนหมายถึงอะไร

---

### 2. Entity Extraction (การดึงข้อมูลสำคัญ)

หลังจากเข้าใจเจตนาแล้ว AI จะ **"ดึงข้อมูลสำคัญ"** ออกมา

```
ข้อความ: "จองรถไปกรุงเทพ 25/12/2025 9โมง-5โมงเย็น"

                    ┌──────────────────┐
                    │ Entity Extractor │
                    └────────┬─────────┘
                             │
         ┌───────────────────┼───────────────────┐
         │                   │                   │
         ▼                   ▼                   ▼
   ┌──────────┐        ┌──────────┐        ┌──────────┐
   │   วันที่   │        │   เวลา   │        │  ปลายทาง  │
   │25/12/2025│        │ 9โมง-5โมง │        │  กรุงเทพ  │
   └──────────┘        └──────────┘        └──────────┘
```

## 🇹🇭 ความท้าทายในการเข้าใจภาษาไทย

### การแปลงวันที่ภาษาไทย

| รูปแบบที่ผู้ใช้พิมพ์ | AI แปลงเป็น |
|-------------------|------------|
| วันนี้ | วันที่ปัจจุบัน |
| พรุ่งนี้ | วันที่ปัจจุบัน + 1 |
| มะรืนนี้ | วันที่ปัจจุบัน + 2 |
| วันจันทร์หน้า | วันจันทร์ถัดไป |
| 25 ธ.ค. | 25 ธันวาคม ปีปัจจุบัน |
| 25/12/2568 | แปลง พ.ศ. → ค.ศ. |

### การแปลงเวลาภาษาไทย

| รูปแบบที่ผู้ใช้พิมพ์ | AI แปลงเป็น |
|-------------------|------------|
| 9 โมงเช้า | 09:00 |
| 9 โมง | 09:00 (เช้า) |
| บ่าย 3 | 15:00 |
| 5 โมงเย็น | 17:00 |
| 2 ทุ่ม | 20:00 |
| เที่ยง | 12:00 |

**หลักการ:** "9 โมง" ต้องเป็นเช้า (09:00) เพราะถ้าเป็น 3 ทุ่ม (21:00) คนไทยจะไม่พูดว่า "9 โมง"

## 🔄 การทำงานแบบ Hybrid (AI + Rules)

```
                    ข้อความผู้ใช้
                         │
                         ▼
              ┌─────────────────────┐
              │    Google Gemini    │
              │    (AI Model)       │
              └──────────┬──────────┘
                         │
            ┌────────────┴────────────┐
            │                         │
     AI เข้าใจได้ ✓              AI ไม่แน่ใจ ?
            │                         │
            ▼                         ▼
    ใช้ผลจาก AI            ┌─────────────────────┐
                          │   Rule-Based Parser  │

                                    │
                                    ▼
```

**ทำไมต้องใช้ Hybrid?**

1. **AI (Google Gemini)** - เก่งเรื่องเข้าใจบริบท ความหมาย
2. **Rules (กฎ)** - แม่นยำ รวดเร็ว ไม่ต้องเรียก API

## 📝 Pattern Matching (การจับคู่รูปแบบ)

### แนวคิด: สอน AI ให้จำ "รูปแบบ"

```
┌─────────────────────────────────────────────────────────┐
│              Pattern: เวลาภาษาไทย                        │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   รูปแบบ: [ตัวเลข] + "โมง" + [เช้า/บ่าย/เย็น]            │
│                                                         │
│   ตัวอย่างที่ตรงกัน:                                      │
│   ├── "9 โมงเช้า"     → 09:00 ✓                         │
│   ├── "5 โมงเย็น"     → 17:00 ✓                         │
│   └── "11 โมง"        → 11:00 ✓                         │
│                                                         │
│   ตัวอย่างที่ไม่ตรง:                                      │
│   ├── "ตอนเช้า"       → ไม่มีตัวเลข ✗                    │
│   └── "สามทุ่ม"       → ไม่ใช่รูปแบบ "โมง" ✗             │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 🗣️ Conversation State (การจัดการบทสนทนา)

AI จดจำว่า **"คุยถึงไหนแล้ว"**

```
┌────────────────────────────────────────────────────────────┐
│                    สถานะการสนทนา                            │
├────────────────────────────────────────────────────────────┤
│                                                            │
│   idle ──────► selecting_date ──────► selecting_vehicle    │
│    │                                        │              │
│    │                                        ▼              │
│    │                              selecting_time           │
│    │                                        │              │
│    │                                        ▼              │
│    │                            selecting_destination      │
│    │                                        │              │
│    │                                        ▼              │
│    └──────────────────────────── confirming_booking        │
│                                             │              │
│                                             ▼              │
│                                         completed          │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

**ตัวอย่างการสนทนา:**

| ลำดับ | ผู้ใช้พิมพ์ | AI ตอบ | สถานะ |
|------|----------|-------|------|
| 1 | "จองรถ" | "จองวันไหนครับ?" | selecting_date |
| 2 | "พรุ่งนี้" | "เลือกรถ..." | selecting_vehicle |
| 3 | "1" | "เวลาไหนครับ?" | selecting_time |
| 4 | "9โมง-5โมงเย็น" | "ไปที่ไหนครับ?" | selecting_destination |
| 5 | "กรุงเทพ" | "ยืนยันการจอง?" | confirming_booking |

```
                              │
```

## ✅ การตรวจสอบความถูกต้อง (Validation)

AI ไม่ได้เชื่อทุกอย่างที่ผู้ใช้บอก - ต้องตรวจสอบก่อน

```
┌─────────────────────────────────────────────────────────────┐
│                    Validation Rules                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1️⃣ วันที่ต้องไม่เป็นอดีต                                     │
│     "จองรถเมื่อวาน" → ❌ ไม่สามารถจองย้อนหลังได้               │
│                                                             │
│  2️⃣ เวลาสิ้นสุดต้องมากกว่าเวลาเริ่ม                           │
│     "9โมงเช้า ถึง 8โมงเช้า" → ❌ เวลาไม่ถูกต้อง                │
│                                                             │
│  3️⃣ ตรวจสอบรถว่าง                                            │
│     ถ้ามีคนจองไปแล้ว → ❌ รถไม่ว่างในช่วงเวลานี้               │
│                                                             │
│  4️⃣ ตรวจสอบสิทธิ์ผู้ใช้                                       │
│     ผู้ใช้ต้องได้รับการอนุมัติก่อน → ✅ หรือ ❌                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 📊 สรุปเทคนิคที่ใช้

| เทคนิค | วัตถุประสงค์ | ตัวอย่าง |
|-------|------------|---------|
| **Intent Recognition** | เข้าใจว่าผู้ใช้ต้องการทำอะไร | "จองรถ" → intent: book_vehicle |
| **Entity Extraction** | ดึงข้อมูลสำคัญจากประโยค | "พรุ่งนี้" → date: 2025-12-24 |
| **Pattern Matching** | จับคู่รูปแบบภาษาไทย | "9โมง" → 09:00 |
| **State Management** | จดจำขั้นตอนการสนทนา | selecting_vehicle → selecting_time |
| **Validation** | ตรวจสอบความถูกต้อง | วันที่ต้องไม่เป็นอดีต |
| **Hybrid AI** | ผสม AI กับกฎที่ตั้งไว้ | Gemini + Thai Parser |

## 🎓 บทเรียนที่ได้

### 1. ภาษาไทยมีความซับซ้อน
- ไม่มีช่องว่างระหว่างคำ
- มีหลายวิธีพูดเรื่องเดียวกัน (9 โมง, เก้าโมง, 9:00)
- ปฏิทิน พ.ศ. vs ค.ศ.

### 2. AI ไม่ใช่คำตอบเดียว
- ใช้ AI เมื่อต้องการความยืดหยุ่น
- ใช้ Rules เมื่อต้องการความแม่นยำ
- **Hybrid = ดีที่สุดของทั้งสองโลก**

### 3. UX สำคัญมาก
- ผู้ใช้ไม่ควรต้องพิมพ์ซ้ำ
- ข้ามขั้นตอนที่ไม่จำเป็น
- แสดง Error message ที่เข้าใจง่าย

## 💡 Q&A

### ถาม: ทำไมไม่ใช้ ChatGPT/Claude โดยตรง?

**ตอบ:** 
- ค่าใช้จ่ายสูงเมื่อมีผู้ใช้มาก
- ความเร็วอาจไม่ทันใจ
- ต้องการควบคุม output ได้

### ถาม: AI เรียนรู้จากผู้ใช้ไหม?

**ตอบ:** 
- ปัจจุบัน: ใช้กฎที่ตั้งไว้ล่วงหน้า
- อนาคต: สามารถเพิ่ม Machine Learning ได้

### ถาม: รองรับภาษาอื่นไหม?

**ตอบ:** 
- ออกแบบให้รองรับได้
- ต้องเพิ่ม Parser สำหรับแต่ละภาษา
